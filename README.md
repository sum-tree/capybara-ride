# 🦫 卡皮巴拉骑单车 · Capybara on a Bike

灵感源自近期大火的 **“鹈鹕骑单车 (Pelican on a Bike)”** 3D 实时渲染基准测试，将主角全面重塑为贴合真实可爱形态的 **卡皮巴拉（水豚）**，并支持 **4 套 3D 骨骼与网格建模方案（按 `V` 切换）**、**4 套主题装扮（按 `X` 切换）** 以及 **蜜柑叠叠乐（抓橘子 🍊）** 玩法！

## ✨ 核心特性

### 1. 深度贴合真实水豚特征的 3D 建模（支持 4 套方案实时切换）
彻底摒弃原版鸟类的“水平悬浮躯干 + 细长管状脖子 + 球形机械关节腿”，重构为真正的水豚解剖与萌系比例：
- **头颈肩一体流线坐姿（[`CS`](./build.js)）**：采用 3D 纵向放样（[`loftY`](./build.js)）打造的圆润敦实梨形/奇异果形身躯稳坐在复古车座上，粗短厚实的肩颈直接与宽大头骨自然过渡。
- **标志性平顶方圆大钝吻（[`buildCapyHeadGeom`](./build.js)）**：宽平头顶（天然适合顶橘子与呆毛）、方中带圆的厚实大鼻头、鼻梁深可可褐渐变毛色、立体竖直人中深沟与微露的两颗圆角白门牙。
- **肉乎乎无球关节四肢（[`buildPlumpLimb`](./build.js)）**：采用带半球重叠封口的有机饱满鸡腿形大腿与小短腿，弯曲踩踏时浑然一体，无任何突兀的机械关节球；脚掌配有肉垫与钝爪。
- **灵动微表情与物理细节（[`E0`](./build.js)）**：
  - **嚼橘子鼓腮帮**：抓到蜜柑咀嚼或按 `H` 咕唧叫时，双颊腮帮子会随下巴咀嚼节奏一鼓一鼓地弹性膨胀！
  - **内凹小圆勺耳高频抖耳**：位于头骨后上方的小圆勺耳会周期性（以及在吃橘子/按喇叭时）触发水豚标志性的高频扇动抖耳。
  - **头顶呆毛与胡须随风摇摆**：额头橘子前方的三簇立体呆毛与吻部微弯胡须随车速与跳跃实时摆动。

### 2. 四套 3D 建模方案（按 `V` 键或点击右上角按钮实时切换）
1. **✨ 方案四 · 蓬松炸毛水豚君（`fluffy`，默认）**：1:1.85 温泉蓬松团子比例，双颊、胸口与臀腿带有多层立体蓬松炸毛簇，搭配大号摇摆呆毛与加长微弯长胡须。
2. **🦫 方案一 · 写实生态原比例（`realistic`）**：1:2.1 自然水豚坐姿比例，一体式粗壮肩颈、真实平顶长方钝吻、高位半眯杏仁眼与三段式栗棕毛流质感。
3. **🥝 方案二 · 治愈毛绒奇异果（`chibi`）**：1:1.45 二头身大头萌系公仔比例，奇异果圆肚、超大鼓鼓仓鼠腮帮子 + 粉嫩腮红、极度松弛的“一字禅意眯眯眼”。
4. **🧸 方案三 · 粘土盲盒手办风（`clay`）**：1:1.65 潮玩盲盒比例，温润哑光粘土材质、独立圆角吐司方鼻块、呆萌外露大白门牙、高光黑曜石豆豆眼，并身穿**定制 3D 蓝色牛仔背带裤（带金扣与卷边裤脚）**！

### 3. 四套配饰与单车主题（按 `X` 键或点击右上角按钮实时切换）
1. **🕶️ 风格 B · 潮酷海岸机车风**：红白青条纹骑行头盔 + 粉色半透明飞行员墨镜 + 复古青色单车。
2. **🍊 风格 A · 经典佛系温泉风**：无遮挡原皮 + 红白条纹针织围巾 + 左腕彩色串珠手链 + 薄荷绿雏菊单车。
3. **👒 风格 C · 日系治愈度假风**：宽檐雏菊编织草帽 + 天蓝围巾 + **前车篮 3D 小黄鸭** + 奶油白复古单车。
4. **⚡ 风格 D · 赛博霓虹夜骑风**：发光青色赛博护目镜 + **头顶发光橘子夜灯（带实时点光源）** + 霓虹流光围巾 + 赛博紫车架与发光青色车轮圈。

## 🚀 运行与构建方式

1. **直接试玩**：双击打开 [`index.html`](./index.html) 或通过任意静态服务器预览。
2. **重新构建与自动化自检**：
   ```bash
   node build.js
   ```

## ⌨️ 快捷键一览

| 按键 | 功能 |
| :--- | :--- |
| `V` | **循环切换 4 套 3D 水豚建模方案**（蓬松水豚君 / 写实生态 / 奇异果Q版 / 粘土背带裤） |
| `X` | **循环切换 4 套配饰与单车主题**（潮酷机车 / 佛系温泉 / 治愈草帽 / 赛博夜骑） |
| `W` / `↑` | 加速踩踏 |
| `S` / `↓` | 刹车减速（滑行有棘轮声） |
| `A` / `D` 或 `←` / `→` | 左右变道收集蜜柑 🍊 |
| `Space`（空格） | 兔跳起飞 |
| `T` | 放手欢呼 + 抬前轮特技 |
| `H` 或 点击水豚 | 水豚“咕唧~ 啾~”叫声 + 高频抖耳 + 鼓腮帮 |
| `B` 或 点击车铃 | 清脆车铃声 |
| `C` | 切换 5 种镜头（自由环绕 / 追随 / 侧面跟拍 / 电影运镜 / 水豚视角） |
| `Q` / `E` | 手动加减档（5 速变速） |
| `N` | 时间快进 3 小时（体验日出、正午、夕阳、星夜银河与萤火虫） |
| `M` | 音乐开关 |
| `K` / `F` / `U` / `P` | 截图保存 / 全屏 / 隐藏 UI / 暂停 |
